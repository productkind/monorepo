The best prompt I've found for fixing a bug with AI is the bug report I'd write for an engineer.

When I was testing discount codes on Little Parrot, a code I knew existed wouldn't apply, so I wrote to Lovable:

"Why couldn't I apply the 'newcode' coupon? I got the 'Invalid coupon code or coupon has expired' error. This coupon exists in Stripe."

Lovable checked the logs and found that the code I'd removed earlier was still applied to the subscription in the backend.

For an engineer or an AI agent, the most useful evidence usually comes from behind the screen: a record in Stripe, a failed request, a line in the server log.
