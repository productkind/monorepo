# Cards: the two outcomes in the SEO indexing email

**One takeaway:** The same page and the same index in both cards. The difference is whether anything stops the page on the way in. **Format:** 2 cards · 1120 x 860 · little-parrot

## Card 1 (in the index)

Visual: one framed card. A document icon labelled your page on the left, a database icon labelled Google's index on the right, one solid arrow between them. Below a dashed rule, the label sits on its own and a plain box hugs the Search Console message. Branding bottom left, the Little Parrot mascot peeking over the bottom edge.

- Kicker, on a gradient highlight: IN THE INDEX
- Left actor: your page
- Right actor: Google's index
- Arrow, left to right, solid. Tag: what happens. Payload: crawled and indexed
- Result label, outside the box: SEARCH CONSOLE SHOWS
- Result, in a box that hugs the text, no drop shadow: URL is on Google.
- Footer handle: LittleParrot.app

## Card 2 (not in the index)

Visual: the same framed card, the same two actors in the same places. The arrow is greyed and a saw-tooth breaks it before it arrives, so the block is what the eye picks up. Below the same dashed rule, the label sits above a plain list. Branding bottom left, the Little Parrot mascot peeking over the bottom edge.

- Kicker, on a gradient highlight: NOT IN THE INDEX
- Left actor: your page
- Right actor: Google's index
- Arrow, left to right, greyed and broken by a saw-tooth part way. Tag: what happens. Payload: blocked before it gets in
- Result label: FIVE THINGS TO CHECK
- Result list, one per line:
  - an accidental noindex tag
  - robots.txt blocking the page
  - incorrect canonical URLs
  - missing internal links
  - the page missing from your sitemap
- Footer handle: LittleParrot.app

## Alt text

Card 1: a diagram of a page that is in Google's index. Your page, drawn as a document, sits on the left and Google's index, drawn as a database, on the right. A solid arrow runs from the page to the index, labelled crawled and indexed, and underneath it Search Console shows the message URL is on Google.

Card 2: a diagram of a page that is not in Google's index, with the same two icons in the same places. The arrow from the page to the index is greyed and a saw-tooth breaks it before it arrives, labelled blocked before it gets in. Underneath are the five things to check: an accidental noindex tag, robots.txt blocking the page, incorrect canonical URLs, missing internal links, and the page missing from your sitemap.

## Design notes

- Card size is 1120 x 860, not the 1080 x 1350 carousel slide: these sit inside the email's 560px content column at 2x.
- Both cards keep the same actor positions and the same arrow geometry, so only the state of the arrow changes between them.
- The outcome block is the same height in both cards, so the two images match when they sit a few paragraphs apart in the email.
