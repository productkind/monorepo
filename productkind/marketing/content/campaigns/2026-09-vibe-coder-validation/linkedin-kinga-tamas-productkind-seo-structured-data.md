If you built your website or app with AI, here’s a 10-minute SEO task worth giving your AI agent:

**Ask it to add structured data to your public pages.**

When a search engine crawls a page, it has to work out what everything means.

Is this page about a person?  
A company?  
A product?  
A course?  
An article?

Structured data lets you explicitly tell it.

For example, instead of hoping Google figures out that a page describes a course, you can add machine-readable metadata that essentially says:

**This is a Course.**  
Its name is X.  
It is provided by Y.  
Here is its description.

This is usually done with Schema.org markup, often as JSON-LD.

Google uses structured data to better understand pages and to power some of its richer search results. And structured information can also make your content easier for AI-powered search systems to interpret.

The nice thing if you're building with AI:

**you don't necessarily need to learn how to write all of this yourself.**

Try giving your coding agent this task:

> Audit all publicly accessible pages of this website. Identify which Schema.org structured data types accurately describe each page and the organisation behind the website. Implement the relevant JSON-LD using the actual information visible on the site. Do not invent missing information. Then validate the implementation against Google's structured data guidelines and tell me what you added to each page.

One important caveat:

Structured data isn't a magic "rank me higher" button.

Think of it more like putting clear labels on your content so machines don't have to infer everything from scratch.

And now that an AI coding agent can do much of the implementation work, it's a surprisingly easy thing to get right.
