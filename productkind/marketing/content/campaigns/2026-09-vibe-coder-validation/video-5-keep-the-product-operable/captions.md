A live app needs ongoing care. A service can fail, a platform can change and an update can break the working version. If you ask an AI agent to fix an outage without an alert or error details, it has to start by working out what failed.

Set up an availability alert. Keep a known working version. Test that you can restore it. Write a recovery checklist while everything is working, so you can follow it when something goes wrong.

## LinkedIn

**Caption:**

If your AI-built app stopped working on Saturday, how would you know?

Set up an alert so a customer isn’t the first person to tell you the app has stopped working. Before launch, give yourself a repeatable way to notice and recover from a problem:

- Set an alert that checks whether the app is available.
- Keep a clearly named working version.
- Back up the data you could not recreate.
- Test that you can restore the app and its data.
- Write the recovery steps while everything is working.
- Schedule regular checks for updates, backups and running costs.

This is one part of the learning path we’re building for women who have already built a product with AI and want to operate it themselves after launch.
