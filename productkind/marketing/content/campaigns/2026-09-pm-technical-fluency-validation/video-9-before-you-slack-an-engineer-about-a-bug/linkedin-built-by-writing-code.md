We built this video with AI. What do you think?

When I hear that someone made a video with AI, I picture a video model generating the canvas.

But you can also make a video by writing code, and that's what we did here. It's a Remotion project, which is React rendered out to video, so every card, pill and icon in those 62 seconds is an element with a position and a little bounce when it appears. Claude Code wrote that code.

We decided on creating this video via code because it's mostly interface: a Slack-ish message, a network panel, a list of seven answers. Video models still can't hold readable text steady between frames, so anything a viewer has to actually read is better drawn than generated.

We crafted the video script, generated the narration with ElevenLabs, wrote the production script, then asked Claude Code to build the components based on that production script.
